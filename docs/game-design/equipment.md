# Основы экипироваки

Наполненность станции элементами устройств, вооружения и экипировки.

1. **Старт = База для работы** Инженер начинает с инструментами для необходимого старта. За исключением глав, сотрудник не должен обладасть со старта предметами из позднего этапа игры.
2. **Прогрессия через сплочённость станции.** Улучшение снаряжения требует кооперации: РНД, Химики, Ботаники и т.д.
3. **Нет лучшему хранилищу/снаряжению.** Каждый выбор имеет минус: вместимость vs скорость vs скрытность.
4. **Визуальная читаемость.** По экипировке должно быть видно роль и угрозу. Синдикатовский скафандр = сразу видно врага.
5. **Восстановимость.** Любое массовое снаряжение можно пересоздать/заказать.

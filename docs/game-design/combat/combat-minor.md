# Минорные Антагонисты

Общий принцип: Антагонист минорного типа создаёт игровые ситуации во время раунда, но не перетягивает внимание раунда полностью на себя.

**3.1.1 Предатель:** Должен присутствовать ресурсный голод. Аплинк не должен покрывать полностью весь необходимый набор экипировки на все случаи жизни.
**3.1.2 Вор:** Вор обязательно остаётся небоевым, скрытным антагонистом. Механически возможная летальность вора - нарушение баланса.
**3.1.3 Крысиный Король:** Количество > Качество. Особенность антагониста остаётся за наращиванием мощи через большое множество управляемых юнитов. Крысиный король не может представлять опасности в одиночку.
**3.1.4 Ревенант:** Видимость = Уязвимость. В астрале ревенант может быть практически недосегаем. При применении способностей - видим и уязвим.
**3.1.5 Ниндзя:** --
**3.1.6 Парадоксальный клон:** Социальная мимикрия, а не боевой антагонист. Механика должна способствовать его мимикрии и не нарушать его скрытность.

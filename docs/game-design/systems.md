# Основы систем

1. **Ресурсы решают.** Нет бесконечных запасов.
2. **Нет одиночкам.** Рецепт/починка/крафт/исследования должны гнать к другому отделу.
3. **Не обязательна, но ощутима.** Отдел может работать без узконаправленного специалиста (химика/робототехника/хирурга/атмоса), но хуже.
4. **Эмерджентность из простого.** Простые устройства -> сложные системы. Нет единственного правильного сетапа. Элемент песочницы.
5. **Театральность > Реализм.** Космос холодный, газ течёт от давления, и т.д. - потому что так понятно игроку, а не потому что так в учебнике.

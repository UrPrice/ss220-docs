# Основы боя

1. **Тактика > Экипировка > Рефлексы.** Побеждает позиция, засада, командная работа.
2. **Тяжесть = Источнику.** Тип урона важнее цифры. Выстрел не должен сравняться с десятком ударов копьём.
3. **Нет ваншотам без цены.** Любая высокая летальность имеет цену: громкость, редкость, расходник, уязвимость.
4. **Право на реакцию.** Даже при низком ТТК бой должен иметь фазу "до выстрела" где жертва может заметить угрозу.
5. **Командная работа > Сумма.** Соло-боец не должен регулярно побеждать подготовленную группу.
6. **Фауна - часть баланса.** Баланс оружия проверяется не только на людях, но и на мобах/мажорах. Если фауна становится беспомощной - баланс сломан.
